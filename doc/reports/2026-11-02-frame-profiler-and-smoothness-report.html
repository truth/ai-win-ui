3 P0 + P1 七项靶向优化技术细节

级别 优化模块 修改文件 根因与修复方案
P0 #1 启动脚本默认 Release 构建 scripts/run_layout_demo.ps1 原脚本固定启动 Debug\ai_win_ui.exe，链接了未优化的 Debug-x64/skia.lib（CPU 软光栅慢 28 倍）。现新增 -Configuration Auto|Release|Debug，交互式运行默认采用 Release，CI -NoLaunch 自动保持 Debug 兼容。
P0 #2 Skia 字体、排版与 SVG 路径三级缓存 src/skia_font_shared.h
src/skia_text_layout.cpp
src/renderer_skia.cpp		 原实现每次调用 CreateDefaultTypeface 均通过 DirectWrite 重新创建 SkTypeface，导致 Skia 内部字形缓存 SkStrikeCache 失效。现对 CreateDefaultTypeface、CreateSkiaTextLayout（4096 项）及 DrawSvgPath 增加哈希缓存。
P0 #3 按需触发 UpdateLayout() src/ui_host.cpp
src/ui_containers.h
src/ui_widgets.h		 移除 UiHost::OnMouseDown 中无条件执行的整页 UpdateLayout()，改为仅在改变组件尺寸的 Expander（折叠/展开）和 AlertBanner（关闭隐藏）中调用 m_context->requestLayout()。
P0 #4 Switch 与 SegmentedControl 140ms 缓动 src/ui_widgets.h 在 16ms OnTimer 帧循环中推进动画进度：Switch 使用 Smoothstep ($3t^2 - 2t^3$) 插值圆钮水平位置与轨道颜色；SegmentedControl 平滑滑动选中态白色胶囊背景。
P0 #5 DIB 64px 步进容量复用与同步重绘 src/renderer_skia.cpp
src/ui_host.cpp		 SkiaRenderer 按 64px 步进对齐分配 GDI DIB 容量（m_dibCapWidth × m_dibCapHeight），拖拽缩放时复用已有位图内存并以 rowBytes = m_dibCapWidth * 4 重新包装 SkSurface；UiHost::OnResize 调用 RedrawWindow(..., RDW_INVALIDATE | RDW_UPDATENOW) 同步上屏。
P1 #6 真局部脏矩形重绘 (Dirty-Rect Culling & Partial BitBlt) src/ui_context.h
src/ui_element.h
src/ui_panels.h / ui_scroll.h
src/renderer_skia.cpp
src/ui_host.cpp		 ① UIElement::InvalidateSelf(padDip) 通过 UIContext::invalidateRect 提交控件局部包围盒；② UiHost 转换为物理像素调用 ::InvalidateRect(m_hwnd, &rc, FALSE)，并在 OnPaint 将 ps.rcPaint 传入 SetDirtyRect；③ SkiaRenderer::BeginFrame 裁剪并仅清除脏区，PresentHwnd 仅对脏矩形区域执行局部 BitBlt；④ Panel、Label、ScrollViewer 通过 IntersectsDirtyRect 剔除不相交子树，将 Switch 动画帧渲染耗时压缩至 0.17 ms。
P1 #7 二次命中 (Two-Hit) 高斯阴影位图缓存 src/renderer_skia.cpp 针对 FillSoftShadow 的 CPU 高斯模糊滤镜，建立 ShadowCacheKey -> {sk_sp<SkImage>, pad, hits} 缓存（上限 256 项）。采用 hits >= 2 二次命中准入策略：窗口缩放中仅出现 1 次的瞬态尺寸直接绘制到主画布，避免离屏表面分配开销；静态卡片与固定控件在第 2 次命中时自动缓存为离屏 SkImage 位图并复用。
