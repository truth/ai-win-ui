# Chart v2 — Phase 1 设计归档 (2026-10-23)

分支：`feature/chart-v2`

## 背景
原有仅 `SparklineChart`：单折线、无坐标轴/标签/交互，XML 无法声明数据。

## 目标
通用 `<Chart>`：多系列、坐标轴、网格、图例、Tooltip；XML/JSON 声明 + Host 动态更新。

## 设计决策
| 项 | 决定 |
|----|------|
| 范围 | 分阶段；Phase 1 做基础（line/bar/area） |
| 声明方式 | `<Chart>` + `<Series type="line\|bar\|area">` 子节点；JSON `props.series` |
| 动态更新 | `Host::SetChartSeriesData` / `SetChartSeriesVisible` |
| 交互 | 悬停十字线 + Tooltip；点击图例切换系列；无缩放/平移 |
| 绘制 | 仅 `IRenderer`（`DrawPolyline`/`FillPolygon`/`FillRect`/`DrawTextW`），无需新增接口 |
| 坐标轴 | 分类 + 数值 X 轴、单 Y 轴（nice-tick）、水平网格 |
| 与 Sparkline | `SparklineChart` 保持不变 |

## 实现
- `src/ui_chart.h`（header-only，经 `ui.h` 引入）：`ChartSeries`、`Chart`、`NiceScale`。
- 布局缓存于 `Render`（plot rect / 图例矩形），供命中测试使用。
- Tooltip 在 `RenderOverlay` 绘制，避免被兄弟控件遮挡。
- 面积图使用 25% 透明度 `FillPolygon`；柱状图按分类分组并排。
- 数值 X 轴仅限折线/面积；含柱状系列时回退分类轴。
- 解析：`src/layout_parser.cpp`（XML + JSON 两条路径）。
- UIA：自动设置摘要 `uiaHelpText`。

## 偏离原计划
- 未新增 `ui_chart.cpp`（header-only）。
- `uia_provider.cpp` 未改动。
- 时间轴/双 Y 轴/对数轴拆至 Phase 2。
